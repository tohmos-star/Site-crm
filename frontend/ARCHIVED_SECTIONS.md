# Архив: вкладки «Тарифы» и «Зоны клуба» в админке (убраны 24.09)

По просьбе — нужен базовый биллинг без тарифов и бонусов, вкладка «Тарифы»
(и всё её содержимое: Типы дней / Группы тарифов / Базовый тариф / Пакеты)
и вкладка «Зоны» (переименованная перед архивацией в «Зоны клуба») убраны
из бокового меню и разметки `frontend/admin/index.html` + логики
`frontend/admin/app.js`.

Бэкенд (`src/modules/tariffs/*`, `src/modules/zones/*`, таблицы `Tariff`,
`TariffRule`, `TariffGroup`, `DayType`, `HolidayOverride`, `LoyaltyTier` и
связь `Tariff.allowedLoyaltyTiers`) **не тронут** — это чисто убор из
админ-UI, схему/бэкенд будем упрощать отдельным шагом ("после этого
соберём базу").

Зоны как данные остаются — устройства всё ещё привязаны к зоне
(`Device.zoneId`), поэтому `ZONES_CACHE`/`populateZoneSelects()` в разделе
"Устройства" никуда не делись, убрана только сама вкладка управления
зонами (список/добавление/цвет/сортировка).

Полная разметка и JS обеих вкладок сохранены в истории git — проще
восстановить оттуда, чем копировать сюда:

- Вкладка «Тарифы» построена в коммитах `734eccc..bdeaf6b` на ветке
  `claude/crm-server-deployment-bmkzrr` (7 коммитов: 4 подвкладки, типы
  дней с цветом, тарифы с типами/доступом по лояльности, пакеты с окном
  отображения, критичный баг-фикс модалки, кнопка удаления).
- Вкладка «Зоны» (список/модалка добавления/сортировка/инлайн-цвет)
  существовала до этого коммита — `git log -p -- frontend/admin/index.html
  frontend/admin/app.js` до коммита архивации покажет полный код.

Восстановление: `git show <commit>:frontend/admin/index.html` /
`app.js` на нужный коммит, перенести секции обратно, добавить пункты
`data-tab="zones"`/`data-tab="tariffs"` в боковое меню и соответствующие
`init*()`/`load*()` вызовы в `DOMContentLoaded`.
