# PC Agent

Нативный Windows-виджет для игровых ПК клуба — устанавливаемое приложение
(не веб-страница), которое:

- при первом запуске просит ввести токен станции (см. «Устройства» в
  админке — `Выдать токен`) и «привязывает» этот ПК к конкретному Device в CRM;
- показывает оставшееся оплаченное время, позволяет продлить сессию,
  завершить её, обратиться в техподдержку;
- по окончании оплаченного времени показывает полноэкранный оверлей поверх
  всего (окон/игр), пока не будет введён новый код или продлено время.

Статус:

- `SetupWindow` — привязка токена станции: ввод, нормализация
  регистра/дефиса/пробелов, проверка через реальный `GET /api/pc/session`
  на живом сервере, сохранение в `%LOCALAPPDATA%\PcAgent\device-token.txt`.
- `MainWindow` — реальный экран станции: если сессии нет, просит код брони
  (`POST /api/pc/redeem-code`); если сессия активна — оставшееся время
  (обновляется раз в секунду), баланс, «+30 мин»/«+60 мин»
  (`POST /api/pc/session/:id/extend`), «Завершить»
  (`POST /api/pc/session/:id/complete`, с подтверждением), «Техподдержка».
- `SupportWindow` — выбор темы + сообщение, но **без реального бэкенда**:
  на сервере ещё нет ручки для заявок в техподдержку, поэтому это просто
  локальное подтверждение (как и в `frontend/pc-widget.html`).
- Ещё не реализовано: полноэкранная блокировка по истечении времени (сейчас
  просто возвращает на экран ввода кода), автозапуск при включении Windows.

Сборка проверяется в CI (см. `.github/workflows/pc-agent-build.yml`) на
`windows-latest`, т.к. песочница разработки — Linux и WPF собрать не может.

## Технологии

- .NET 8, WPF (`net8.0-windows`) — выбран вместо Electron из-за заметно
  меньшего потребления ресурсов (нативный рендеринг, без встроенного
  Chromium/Node.js), что важно на игровом ПК.

## Сборка локально (только на Windows)

```powershell
cd pc-agent
dotnet build
dotnet run
```

Собрать или запустить это можно только на Windows — песочница разработки
(Linux) не поддерживает WPF, поэтому здесь используется CI на
`windows-latest` для проверки, что код вообще компилируется.
