# PC Agent

Нативный Windows-виджет для игровых ПК клуба — устанавливаемое приложение
(не веб-страница), которое:

- при первом запуске просит ввести токен станции (см. «Устройства» в
  админке — `Выдать токен`) и «привязывает» этот ПК к конкретному Device в CRM;
- показывает оставшееся оплаченное время, позволяет продлить сессию,
  завершить её, обратиться в техподдержку;
- по окончании оплаченного времени показывает полноэкранный оверлей поверх
  всего (окон/игр), пока не будет введён новый код или продлено время.

Статус: только скелет проекта, подтверждающий, что WPF-приложение
компилируется в CI (см. `.github/workflows/pc-agent-build.yml`, ubuntu — это
Linux-песочница разработки, WPF собрать не может, поэтому сборка идёт на
`windows-latest`). Реальная логика (привязка токена, опрос `/api/pc/*`,
полноэкранная блокировка, автозапуск) ещё не реализована.

## Технологии

- .NET 8, WPF (`net8.0-windows`) — выбран вместо Electron из-за заметно
  меньшего потребления ресурсов (нативный рендеринг, без встроенного
  Chromium/Node.js), что важно на игровом ПК.

## Сборка локально (только на Windows)

```powershell
cd pc-agent
dotnet build
dotnet run
```

Собрать или запустить это можно только на Windows — песочница разработки
(Linux) не поддерживает WPF, поэтому здесь используется CI на
`windows-latest` для проверки, что код вообще компилируется.
